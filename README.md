# Number Guessing Game 🎯

My second Python project — a simple number guessing game built using Python.

The computer randomly selects a number between 1 and 10, and the player has 3 chances to guess it correctly.

## Features
- Random number generation
- 3 chances to guess the secret number
- Hints to guess higher or lower
- Win and lose conditions

## How to Run

Make sure Python 3 is installed on your computer.

```bash
python3 guessing_game.py
```

## How to Play
1. Run the program.
2. Enter a number between 1 and 10.
3. Follow the hints to guess higher or lower.
4. Guess correctly within 3 chances to win!
